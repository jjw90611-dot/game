## CPU AI 공정성 검증

- CPU 의사결정 모듈은 외부 LLM/API를 사용하지 않으며 서버 내부 규칙 기반으로 동작함.
- 역할의 비밀정보를 무제한으로 읽어 판단하지 않도록 역할별 허용 정보 함수를 분리함.
- 멀린: 모르드레드 제외 악을 인지.
- 퍼시벌: 멀린 또는 멀린/모르가나 후보만 인지.
- 일반 악: 규칙상 보이는 악 동료만 인지하며 오베론은 제외.
- 오베론/악 란슬롯: 일반 악 동료 정보를 받지 않음.
- 암살: 공개 원정/투표 이력과 규칙상 알고 있는 악 동료 정보로 후보를 평가.

## CPU 음성/영상 정책

- 사회자 음성은 기존처럼 Yuna 고정.
- CPU 발언은 Yuna가 아닌 한국어 음성을 우선 탐색하여 CPU별 다른 voice profile을 적용.
- 기기에 한국어 음성이 충분하지 않으면 동일 음성에서도 속도/피치를 조금씩 달리해 구분함.
- 실제 사용 가능한 음성 목록은 각 휴대폰 OS/브라우저에 따라 달라질 수 있음.
- CPU는 영상/마이크 스트림을 생성하지 않아 CPU 추가 자체로 TURN 영상 트래픽이 증가하지 않음.
